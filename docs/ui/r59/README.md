## 覆盖汇总

- **页面 9 个**：工作台 / 订单列表 / 订单详情 / 报价 / 打样单 / 商品库 / 客户 / 报表 / 设置
- **收款状态标签 8/8 全露脸**：草稿、待确认、客户已确认、部分收款、定金已收、已结清、已失效、已作废
- **弹窗/交互形态 29 个**：含 PI/CI/PL/报价单/样品单五张纸的预览、新建/编辑四类、收款、核销、失效、作废（含勾选确认）、批次创建、报价/打样转订单、远端登录四态
- **无 UI 形态的领域**：CSV 导出（订单台账/月度汇总/收款台账/品号明细/全量底稿）、备份 ZIP、编号跳号与查重、PL 分批出货的库存扣减、操作历史明细——这些只有数据层断言，界面上没有独立页面形态
