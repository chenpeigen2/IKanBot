本轮界面变更一处：**设置页「数据备份」卡下新增「最近一次恢复的搬迁对账」块**——恢复成功
（本机重启后 / 远端刷新后）把恢复后库里现算的对账亮出来：12 张核心表逐表行数、收款合计、

语义退出、本帧无图属预期；帧 2 新进程启动补算后对账卡出现）。第二张「带客户预收余额」为
数据预置摆拍（seed 库多收 100 进预收后预置对账），表格与余额行的渲染形态一致。
