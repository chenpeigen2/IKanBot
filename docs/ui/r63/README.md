# R63 截图矩阵（2026-11-08）—— M4 第二片「有人正在改」弱提示

本轮界面变更一处：**详情/编辑面开着时，别人改过这条账会出一条不拦操作的黄条弱提示**
（`src/renderer/src/hooks/useStaleSnapshot.ts`，每 30 秒 + 窗口聚焦时拉最新 row_version
与你手里快照比对）。接线六处：订单编辑弹窗、订单详情、客户编辑、商品编辑、报价编辑、打样编辑；
报价/打样同时补上了保存时回传 `expectedRowVersion`（此前 CAS 在这两张单的界面上是空转的）。

拍法：`scripts/shot.sh`，数据目录先 `npm run seed`（截图模式不触发自动备份——本轮顺带修的，
否则 sweep/截图起一次应用就把「还没有成功备份」的提醒吃掉）；「别人改过」用截图 JS 直调
`window.api.*.save/update` 模拟另一窗口写一笔，再 `window.dispatchEvent(new Event('focus'))`
触发钩子立刻盯一轮。
