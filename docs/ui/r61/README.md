## 本轮大件（备份簇上后端）的画面说明

远端模式备份 = 服务器侧打包（库 + 图片目录 + 单据存档目录整包，同一份 core/backup.ts），
桌面只转发与展示；服务器的定时器照「每天启动一备 + 每小时补查」自己跑——截图里那条
`ikanbot-20261107082837-auto.zip` 就是服务器启动 10 秒后自动压出来的，不是手工点的。
恢复期间服务器把业务请求挡回去（「恢复期间请全员停手」，HTTP 冒烟有断言），完整并发方案留 M4/M5。

「401 清假登录态」没有独立画面：它的可见效果是登录卡从「已登录：某某」变回未登录表单——
形态就是 settings-backup-remote.png 里的登录卡（未登录态长这样，只是反着变），
行为由双模式测试「401 后 mode:get 回到未登录」「主进程通知了界面」锁着。
