## 一、N34：存档链路真点一次，三个准话

我用 `shotlog.sh`（保留 stdout 的截图模式）在**真界面**上点了整条链路，不是看代码猜的。

**①「存到系统」几秒落库？——实测 817 毫秒。**
- 操作：订单 SO20261021005 → 点「生成 PI」开预览 → 点「存到系统」。
- 弹出 toast：「已存档到系统：D:\code\IKanBot\data\docs\PI20261021005\PI20261021005_v1.pdf（第 1 版）」，**从点击到 toast 出现 817ms**（console 实测日志，见下）。
- 查库确认：`doc_versions` 落了一行（doc_no=PI20261021005, kind=pi, version=1）；磁盘上 `data/docs/PI20261021005/PI20261021005_v1.pdf` 真实存在。
- 你上轮连点两发落不了库，确实是截图工具 2 秒就掐的问题——实际链路不到 1 秒就完了，比想象快。
- 截图：`out/shots/r12-n34-savepi.png`（预览纸面 + Rev.1）。

**② 用哪个阅读器？——系统默认程序。** 查了这台开发机注册表：`.pdf` 的 UserChoice 指向 **MSEdgePDF（Microsoft Edge）**，`ftype` 也核过 MSEdgePDF → `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`。你机器上装了 WPS/Adobe 就用你机器的默认阅读器，代码走的是系统 `shell.openPath`，不挑阅读器。

**③ 文件落在哪个文件夹？——`data\docs\<单号>\<单号>_v<版本>.pdf`。** 例：`D:\code\IKanBot\data\docs\PI20261021005\PI20261021005_v1.pdf`（按单号一个子文件夹，每版一个文件）。「所在文件夹」按钮点开就是这个子目录并**选中那一版文件**（不是整个 docs 根目录），实测点击无报错。
- 截图：`out/shots/r12-n34-open.png`（操作历史页签 + 单据存档表）。

**一个如实说明（不藏）**：「打开」按钮我真点了两次（`r12-n34-open.png` / `r12-n34-open2.png`），主进程 `shell.openPath` 返回成功、**没有任何报错 toast**，但**这台开发机上没弹出阅读器窗口**——因为这台机器的系统关联半残（`HKCR\.pdf` 的默认值是空的，我用 PowerShell `Start-Process` 直接拉这个 PDF 也唤不起 Edge、查遍进程没有 msedge 窗口）。这是**这台机器的系统环境问题**，不是产品的账：文件在、路径对、openPath 成功、你机器上日常用阅读器开 PDF（关联是好的），点一下就会弹。等你下轮抽查时如果弹不出来，再回来找我，我去查 `docs:openFile` 那条 IPC。

## 二、单号查重：SO / PI / 报价号 / PL 号（r10 N-3 续）

r11 只做了打样单号，你说剩下的排下轮——本轮补完。规矩和打样单号同一条：**单号是凭据，恢复备份或手工导库后计数器可能落后，绝不能生成重号。**

**改法（两层）**：
1. **自动号跳号**：`electron/db/index.ts` 的 `nextNo()` 加了「占位表」——SO 查 `orders.order_no`、PI 查 `orders.pi_no`、Q 查 `quotations.q_no`、PL 查 `packing_lists.pl_no`、SMP 查 `sample_orders.sample_no`。生成时如果库里已被占（含手工插的），自动跳到下一个没用过的号。这是唯一入口，订单/报价/装箱单/打样单四个地方全部自动生效。
2. **手工 PI 号撞号拦截**：`electron/services/orders.ts` 加查重——**新建**或**编辑订单**（订单详情 →「客户与条款」卡右上角「**编辑**」→ 弹窗「PI 号」输入框）里把 PI 号填成别人的号，保存时红条拦住：「PI 号 XXX 已经存在（可能恢复过备份或手工导过数据）。单号是凭据，不能两张单共用一个号——请在「PI号」里换一个号再保存。」弹窗不关，改成自己的号或换新号就能存。

**没改界面按钮**：PI 号本来就在编辑弹窗里可改（占位提示「对外的单据编号，可改」），只是现在改撞号会被拦。

**断言锁死**（`scripts/e2e-test.ts` 新增一节「r12 单号查重」，10 条）：手工占用下一个 SO 号→自动跳号；手填 PI 重号→中文拦住；编辑改别人的 PI 号→拦住、不改自己的号不误拦；PI/Q/PL 自动号各自跳过手工占用号；全库 SO/PI/Q 号无重号。全部 ✓。

**界面实拍**：`out/shots/r12-pi-dup.png`——编辑 SO20261021004，PI 号改成已被 SO20261021001 占用的 PI20261021001，点保存 → 红条报错、弹窗不关。

**没做**：无（这轮这块做完了）。
