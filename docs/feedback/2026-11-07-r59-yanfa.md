## 第二刀：M2 鉴权第一片

### 服务端 —— **已做并验过**

- **登录**：`POST /api/auth/login`（用户名+密码 → token，12 小时）。密码哈希用 node 内置 `crypto.scrypt`（随机盐 + `timingSafeEqual`），token 用 node 内置 HMAC-SHA256——**没引任何新依赖**，理由在 backend-plan 记账。
- **首个用户引导**：启动时 users 表为空且设了 `IKAN_BOOTSTRAP_USER` / `IKAN_BOOTSTRAP_PASSWORD`（可加 `IKAN_BOOTSTRAP_NAME`）就建一个；没设齐只打警告照常启动（此时全接口 401，是安全的）。操作步骤写进了 backend-plan。
- **全路由闸门**：除 `/healthz`、`GET /api`、`/api/auth/login`、GET 图片直链外全要 Bearer，401 统一中文「请先登录：打开『设置 · 数据来源』…」。错密码与查无此人回同一句「用户名或密码不对」，不告诉试探的人用户名存不存在。
- **actor 从 token 注入（留痕真实性，重点测了）**：`core/actor.ts` 用 AsyncLocalStorage 把 token 认定的身份套住整个请求调用链；order_events、预收抵扣、退款撤销的操作人**先认 token 认定的身份**，本地模式回落 settings.operator（桌面本地行为一字不变）。测试故意把 settings.operator 写成「界面上传的名字不算数」，断言历史里只有 token 里的「周文娟」。
- **秘钥**：`IKAN_AUTH_SECRET` 优先；没给就自动生成存库文件旁 `.auth-secret`（重启不变，重启就全员登出不可接受）。丢了 = 全员重新登录，可接受。
- **挂账（明确的取舍）**：GET 图片直链本片不挂鉴权——`<img>` 发不了 Authorization 头，挂了远端模式商品卡全白；签名 URL 按 M5 计划补。局域网内能看到图，账打不开。

测试（服务端，先红后绿）：HTTP 冒烟 161→**169**（+8：发 token/错密码拒/无 token 401/编的 token 401/公开入口不挂锁/actor 三连）；数据层 56→**69**（+13，含 stash 里那份 WIP 的全部断言）。

### 桌面远端模式 —— **已做并验过**

- token 经 **safeStorage** 加密落 userData（`electron/remote/token-store.ts`），渲染层只见「登的是谁」，拿不到 token 本体；新通道 `mode:login` / `mode:logout`（四层打通：token-store → client → ipc → preload → api.ts → 设置页）。
- 所有远端请求（业务通道、CSV 导出、图片上传/丢弃）自动带 Bearer；没登录就让后端 401 说人话。
- **设置页「数据来源」卡升级**：远端模式才出现登录卡（用户名+密码+登录，回车可提交）；登录后显示「已登录：周文娟（wenjuan）」+「退出登录」。本地模式**一行未改**——登录框只住在 remote 分支里，e2e 有断言盯着。
- **不白屏不假死**：没登录时各页面只坏当场那一块，设置页的加载失败下面仍摆着数据来源卡（登录就在下面，不用重启）。三张实拍：`out/shots/r59-settings-login.png`（登录表单+401 提示）、`r59-settings-logged-in.png`（已登录+退出按钮）、`r59-orders-remote.png`（带 token 拉到服务端真实数据，状态标签全对）。
- 已有的模式切换、探活、覆盖率**没退化**：双模式 107→**116**（+9 全是新鉴权断言：未登录被拒、错密码、空用户名本地先拦、登录态、token 加密落盘、登出/重登全链路）。
