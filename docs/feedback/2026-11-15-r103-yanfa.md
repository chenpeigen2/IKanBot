# R103 研发报告 —— 审计静态路由扫描覆盖空装饰器（110 vs 108 盲区收口）

日期：2026-11-15。基线 v0.5.45。每条标「已做并验过 / 已做但没验 / 没做（原因）」。
本轮改动在**审计共享件与自测**（无渲染层改动：无 UI 形态，无截图义务，证据为审计输出与
断言结果）。

## 一、做了什么

1. **根因定位**（已做并验过）：`scripts/lib/audit-shared.cjs` 的 `controllerRoutes()` 原先
   只识别带非空字符串参数的装饰器，漏掉两个空装饰器写法：
   - `server/src/health/health.controller.ts` 的 `@Controller()` + `@Get('healthz')`
   - `server/src/meta/meta.controller.ts` 的 `@Controller('api')` + `@Get()`

   这两条正好是 `GET /healthz` 与 `GET /api`，也是运行时 `routes.service.ts` 自描述 110 条
   与静态审计 108 条的唯一差额。
2. **空装饰器扫描**（已做并验过）：`controllerRoutes()` 改为同时接受空参数与带引号参数；
   `@Controller()` 的 base 记为空串，`@Get()` 等方法的 sub 记为空串。单双引号、空白与原有
   `@Post/@Get/@Put/@Delete/@Patch` 全部保留。
3. **路径拼接对齐运行时**（已做并验过）：新增 `joinPath(base, sub)`，与
   `server/src/meta/routes.service.ts` 同款：去两端斜杠、滤空段、补根斜杠。结果不会出现
   `//healthz` 或 `/api/` 之类的畸形路由。
4. **自测补两条锁**（已做并验过）：`scripts/audit-route-match-test.cjs` 从 18 项增到 20 项：
   - 空 `@Controller()` / `@Get()` 必须进入静态路由表，且分别命中 `/healthz` 与 `/api`；
   - 静态控制器路由总数必须为 110，与运行时自描述对齐。
5. **文档口径同步**（已做并验过）：`scripts/audit-http-coverage.cjs` 顶部补 R103 说明；
   `README.md` 的断言规模改为 `audit:http` 110/110、`audit:route-match` 20 项。

## 三、红验证（每次篡改后均已还原）

1. **旧扫描下 `audit:http` 仍是绿的**（已做并验过）：临时把 `controllerRoutes()` 还原成
   只认非空装饰器的旧实现，`npm run audit:http` 输出总路由 108、功能断言引用 108、exit 0。
   这证明该盲区是**静默漏扫**：漏掉的路由不会出现在「未覆盖」清单里，单靠 `audit:http`
   自己发现不了。交接摘要里「旧扫描会报两条未覆盖」的预期不成立，已按实跑结果纠正。
2. **新增自测在旧扫描下报红**（已做并验过）：同一旧实现下 `npm run audit:route-match`
   exit 1，失败点为「空 `@Controller()` / `@Get()` 装饰器进入静态路由表」，断言直接指出
   `/healthz` 未被扫到。这是本轮可复现的红。
3. **恢复新实现后全绿**（已做并验过）：`audit:route-match` 20 项全过，`audit:http`
   110/110，`audit:ipc` server 路由 110，均为 exit 0；`git diff` 复核无临时残留。

## 四、没做什么 / 挂账

  改成依赖运行时发现机制）**。
- 业务逻辑、数据库、运行时路由：**没做（原因：本轮零业务改动，范围仅审计脚本与文档）**。
- 渲染层截图：**没做（原因：本轮零渲染层改动，无 UI 形态，按项目规则无截图义务）**。
- MySQL / M5、CI 覆盖面扩充、e2e DOM 工装：**维持既有挂账（原因：不在本轮范围）**。

## 五、请复验的重点

1. 空装饰器两条路由是否真被静态扫描命中：`GET /healthz`、`GET /api`，且路径无重复斜杠/
   尾斜杠。
2. 静态总数 110 是否与运行时自描述、e2e 的 `routes.length === 110` 一致。
3. 旧扫描的红是否落在新增自测上（而不是误以为 `audit:http` 会自己报两条未覆盖）。
4. 全量回归与三套审计数字是否与本报告一致。
