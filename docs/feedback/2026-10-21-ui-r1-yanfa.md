## 五、typecheck / test:e2e 结果

```
npm run typecheck   → 通过，零错误
npm run test:e2e    → 通过 379 项，失败 0 项（与本轮开始前的基线一致）
```

**为什么 UI 改动不影响 e2e**：这轮改的全是**呈现层**（CSS 变量、className、静态文案），没有动任何取数、金额计算、状态流转、数据库结构。`test:e2e` 走的是 `electron/services` 里的业务接口，接口签名和返回值一个没变，所以 379 项断言的输入输出完全一致，**基线持平**。
唯一动了数据结构的地方是 `Dashboard` 的「最近订单」表把「金额 / 件数」拆成两列 —— 拆的是**同一个数组的同一份数据**，没加字段没改字段。
