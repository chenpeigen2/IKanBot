## 四、本轮新发现的问题

### N27. **客户临时加单，收款状态不重算 —— 系统还写着"已收款"，其实新定金没收齐**（致命）

- **场景**：客户上午说"再加 500 件"。这是我这行最常发生的事，**客户临时改单**。
- **我现在的做法**：在订单详情的「商品明细」里，把数量 1000 改成 1500（失焦就存），然后出新版 PI 发给客户。
- **痛在哪**：我实测了一遍（截图 `r5-restatus2.png`，是我自己在程序里建的一单）：

  | | 数量 | 订单金额 | **新定金** | 已收 | **状态** |
  |---|---|---|---|---|---|
  | 改之前 | 1000 | 8,000 | 2,400 | 2,400 | **已收款** |
  | 客户加 500 之后 | 1500 | 12,000 | **3,600** | 2,400 | **还是「已收款」** ❌ |

  1. **定金已经从 2,400 变成 3,600，我实际只收到 2,400，差 1,200 USD。**
     但状态标签**一动不动**，还是「已收款」四个字。我要是只看标签，我就会跟客户说"定金已收齐"，
     **或者在催款提醒里看不到这一单**（催尾款提醒是按"已收过钱但没收齐"筛的，状态是「已收款」也还算命中，
     但我要是按"已收款"标签去筛"不用催的单"，这一单就被漏掉了）。
  2. **PI 上印的 Deposit 是 3,600**，客户照着 PI 付款就会付 3,600；我这边系统以为 2,400 就够了。
     **两张纸、两个数，我跟客户对不上。**
  3. **同一个页面里两套规则**：改「费用（运费/保险）」会重算收款状态，改「整单信息」会重算，
     **唯独改明细（数量/单价/颜色/尺码）、加一行、删一行都不重算。**
     代码里就是 `updateOrderItem()` / `addOrderItem()` / `removeOrderItem()` 三个函数
     **没有调 `recomputePaymentStatus()`**，而 `updateOrder()` / `updateOrderCharges()` 调了。
  4. 反过来更危险：客户**减** 500 件，总额降到 8,000 以下、已收 3,000 已经超了，
     状态还是「已收款」（**永远不会变成「已结清」**），待收那栏会显示一个**负数**。
- **想要什么**：
  1. **改数量、改单价、加一行、删一行，统统自动重算收款状态**，并且在操作历史里记一条
     「收款状态自动流转为 partial」这种，跟记收款时一样。
  2. **重算的方向要能退**：加单加到收不够要从「已收款」退回「部分收款」；
     减单减到收够了要从「部分收款」升到「已结清」。现在只会往上走不会往下走。
  3. 顺便：明细金额一变，PI 上的 Deposit 也要跟着变（这个其实是对的，我查了 `depositAmount = 含费用合计 × 比例`，
     实时算的，**这条没问题**）—— 我要的是**状态**跟上。
- **重要性**：**致命**。这是"客户临时改单"这个头号场景，是我最怕出错的地方，而且错的是**真金白银**。

### N28. **删一单 = 把已经收到的钱和所有操作记录一起抹掉**（很重要）

- **场景**：我建错了一单（客户重复下单、我把两个订单建成了一个），想删掉重开。
  或者客户取消了这单，要撤掉。
- **我现在的做法**：订单列表右边有红色「删除」，详情页右上角也有「删除订单」，
  弹一句 `确认删除订单 SO20261021001？删了就找不回来了。` 就删了。
- **痛在哪**：
  1. **它没有告诉我这一单收了多少钱。** 我实测：建一单 → 记一笔 240 USD 的定金（银行流水号 TEST9911）→
     点删除 → 查库：`payments` 表里这行**没了**，`order_events` 里我加的收款记录**没了**，
     报表「累计收款」也跟着少了 240。**截图 `r5-delorder.png`：删完 `orders.get()` 返回 null。**
  2. **老板的规矩原话**：「所有订单必须走公司系统留痕，因为要退税、要做信用证、万一客户赖账得有凭据」。
     **现在这个"删除"按钮，是唯一能让凭据消失的口子。** 客户赖账，我拿不出"我什么时候收到过钱"的记录，
     唯一的办法是去翻邮件银行流水 —— 那就等于这套系统白用了。
  3. **PI 文件还在硬盘上，数据库里却没这单了。** 单据存档目录 `data/docs/PI20261021001/…` 里躺着 PDF，
     系统里查不到任何一单 —— **对不上账**。
  4. 最要命的场景：**客户已经汇了定金，我发现单建错了，删掉重开 —— 收款记录被我亲手抹了。**
     我得回邮件翻银行流水号重敲一遍，运气不好还敲错。
- **想要什么**：
  1. **删之前必须告诉我这单的状态**：弹窗里写「这一单**已收 USD 3,000.00**（含费用合计 7,805.00），
     删了以后收款记录和操作历史会一起没有，确定吗？」—— **让我自己判断，不是不让我删。**
  2. **更好：给订单加一个「已作废 / 客户取消」状态**（像报价单那个「已失效」），**状态一变就不进销售额、
     不进待收款、不进毛利，但记录还在**。真要删也应该只给"新建客户时打错字"这种场景用。
  3. 单据存档的 PDF 跟着删还是留着，也给我个说法。
- **重要性**：**很重要**。（不是算错钱，是**我自己给自己留后门**：系统说"留痕"，我一脚就能把痕踢掉。）

### N29. **同一个"这单多少钱/欠多少"，在六个地方六个数**（很重要）

- **我现在的做法**：我去六个地方抄，抄出六个数：

  | 订单详情（SO20261021001） | 订单金额 **USD 7,575.00**，下面小字「含费用合计 USD 7,805.00」，待收 USD 4,805.00 | 货值 + 费用 − 已收 ✅ |

  | **订单列表**（截图 `r5-orders.png`） | 金额 **USD 7,575.00**、已收 USD 3,000.00 | **不含费用，也不显示待收** ❌ |
  | **导出的「订单台账.csv」** | 订单金额 **7,575**、已收 **3,000** | **不含费用；没有费用列、没有待收列** ❌ |
  | 客户页「未收金额」 | Acme **CNY 55,019.25** + Nordic CNY 6,077.50 = **61,096.75** | 货值 − 已收，**不含费用** ❌ |
  | **工作台「待收款金额」** | **CNY 82,546.75** | 未结清订单货值求和，**不减已收、不含费用** ❌ |
  | **单据存档表的「金额」列** | PI 那一行 7,805，**PL 那一行 7,575** | 同一单的两种金额 ❌ |

- **痛在哪**：

     **工作台多报 19,805.50 元（虚高 31.6%）；客户页少报 1,644.50 元（运费保险没进去）。**
  2. **「导出 Excel」是老板最常要的那个文件。** 我导出的订单台账里，SO20261021001 的「订单金额」是 7,575，
     可这单 PI 上白纸黑字印的是 7,805。**我拿这个 CSV 去跟老板对账，他一比单据就知道少了两百多美金。**
  3. **订单列表没有「待收」这一列**，我只看到一个「金额 7,575」和一个「已收 3,000」。
     我想知道还差多少，得点进每一单去减。**一天几十单，我点到手废。**
  4. 上轮我说的 N22（工作台 + 客户页）**一个字没改**，这一轮我又找出**订单列表、导出 CSV、单据存档金额列**三个新地点。

  1. **一个口径，一个数**。我不管你在后台怎么算，**"这单一共欠多少"在订单列表、订单详情、PI、CI、

  3. **导出的订单台账要么给"含费用合计"和"待收"两列，要么就别导一个跟单据对不上的数。**

### N30. **删了一行明细，系统里查不到**（很重要）

- **场景**：客户说"Black 的 M 码不要了"、"这个颜色取消"。我在明细表里点「删除」删掉那一行。
- **我现在的做法**：点删除，有一句 `删除 TS-001 Black/M？` 的确认，然后这行就没了。
- **痛在哪**（实测，截图 `r5-delitem.png`）：
  - 建单 → 加 TS-001 Black/M ×100 → 加 PL-002 Navy/L ×50 → 删掉 PL-002 那行。
  - 操作历史里只剩三条：`创建订单` / `添加 SKU TS-001 Black/M × 100` / `添加 SKU PL-002 Navy/L × 50`。
  - **没有任何一条说"删除了 PL-002 Navy/L × 50"。** 改数量是有记录的（`修改明细 TS-001：数量 1000 → 1500`），
    **删行没有。**
  - **删掉的那一行，在系统里等于从来没存在过。** 客户下过 50 件 PL-002，后来取消了 —— 这件事系统不记得。
  - 老板查"这个客户到底要过什么"，看到的是"加过 PL-002 Navy/L ×50"，**看不出它最后被取消了**，
    数量也对不上报关单。**跟"改数量"能留痕、"删行"不能留痕，比"什么都不记"更坑 —— 它记了一半。**
- **想要什么**：
  1. **删行也记一条操作历史**：「删除 SKU PL-002 Navy/L × 50（单价 12.50）」。
  2. 顺便：**装箱单明细增删改也不记**（`addPackingListLine` / `deletePackingListLine` / `updatePackingListLine`
     都没调 `logEvent`），箱数、净重被改过也查不到。**报关单跟箱单一对不上的时候，我要凭据。**
- **重要性**：**很重要**。（就差一条记录的事，但这是老板要的"凭据"。）

### N31. **报价单删了，已经转出来的订单还在，但报价单查不到了**（有点烦）

- **场景**：一张报价单转成了订单，后来发现报价单上写错了（比如费用写错了），我想删掉重来。
- **我现在的做法**：报价单列表每行都有红色「删除」，一句 `确认删除报价单 Q20261021002？` 就删了。
- **痛在哪**（实测，截图 `r5-delquot.png`）：
  - 建报价单 Q20261021002 → 转订单 SO20261021008（4,000 USD）→ **删除报价单**。
  - 结果：`quotations.get()` 返回 **null**（报价单没了），**订单还在**，金额 4,000，
    订单的操作历史里只剩一句「由报价单 Q20261021002 转成订单，商品明细原样带入（汇率 7.15，汇率日期 2026-10-21）」。
  - **也就是说：这单是从哪张报价来的，我只能在操作历史里看到一句编号，点进去是空的。**
    报价单上客户的原始报价、砍价记录、改了几版，**全没了**。
  - 硬盘上 `data/docs/Q20261021002/` 里那几张报价单 PDF 还躺着，**系统里却已经不认识这个编号了**。
- **想要什么**：
  1. **已转成订单的报价单，别让删**（或者删之前明说「这张已经转成 SO20261021008，删了以后就查不到原始报价了」）。
  2. 报价单加个「已作废」状态，跟订单的「已失效」一样。
- **重要性**：**有点烦**。（一年 200 单，报价单转单率不高，但真删错一次就少一份跟客户对账的凭据。）

### N32. **删客户弹一句英文数据库报错**（有点烦）

- **场景**：客户倒闭了/我建错了一个客户，想把这个客户档案删掉。
- **我现在的做法**：客户列表红色「删除」→ 确认 → 弹一个红色的 toast。
- **痛在哪**（实测，截图 `r5-delcust.png`）：这个客户有订单，弹出来的是
  **`Error: FOREIGN KEY constraint failed`** —— 一句英文数据库报错。
  1. **有历史订单的客户根本删不掉**（数据库外键挡着），**而且它不告诉你为什么**，
     就甩一句英文给老板看。老板会以为软件坏了。
  2. 我要删的大概率就是"我建错了没用的客户"，可万一是个有订单的客户，我以为删了，
     实际没删掉，**下次建单选到这个"要删"的名字上，更麻烦**。
- **想要什么**：
  1. 弹人话：**「Acme Fashion GmbH 有 3 个订单，不能删。要删请先把订单处理掉。」**
  2. 或者给客户也加个「停用/不再合作」的标记，这样建单的时候选不到它，但历史记录留着。
- **重要性**：**有点烦**。

### N33. **打样单的「合计（公司垫付）」这个数本身是错的**（有点烦）

- **场景**：客户要打样，我寄 DHL，样品费 50、快递费 120。
- **我现在的做法**：打样单编辑弹窗里填「样品单价」「快递费」，底下自动出：
  `样品费合计 50.00` / `快递费 120.00` / **`合计（公司垫付）170.00`**（截图 `r5-sample-edit.png`）。
- **痛在哪**：
  1. **这 170 是个没有意义的数。** 样品费 50 是**客户该给我的**，
     快递费 120 是**我自己掏的**（字段名自己都写着「快递费（公司垫的钱）」）。
     **一个是应收，一个是垫付，加在一起叫什么"公司垫付"？**
     客户把样品费 50 付了以后，公司实际只垫了 120，不是 170；
     客户不付，公司赔 170 —— **到底赔多少，系统算不出来。**
  2. **打样单里没有"公司实际成本"这个字段。** 工厂打样费我付了多少、快递实际花了多少，
     系统里一个字都没有。**年底老板问"今年打样一共亏了多少"，我只能翻微信支付记录。**
  3. 这跟 N23（垫的钱没进应收）是连着的：**系统帮我记了"我收了客户多少"和"我垫了快递费"，
     但没帮我记"公司一共垫了多少、该收回多少"。**
- **想要什么**：
  1. 打样单上分清三笔：**样品费（应收客户）/ 快递费（公司垫付）/ 公司成本（工厂打样费+实际快递费）**，
     然后给我一个真的"公司净垫 = 成本 − 已收"。
  2. 再加上"客户已付 / 下单抵扣 / 客户免单"三个标记（免单也要留记录，别让我靠回忆）。
- **重要性**：**有点烦**。（金额不大，但"系统替我记住了我垫的钱"这件事，现在记的是个糊涂账。）

### N34. **单据存档表里列了每一版，可我一版都打不开**（有点烦）

- **场景**：客户说"我们按 PI 第 1 版付款"，或者我要把上一版重新发给客户。
- **我现在的做法**：订单详情最下面「单据存档（出过的每一版）」表，列出单据号 / 版本 / 金额 / 时间，
  每一行右边只有一个 **「打开目录」** 按钮。
- **痛在哪**：
  1. 这个按钮打开的是**整个 `data/docs/` 目录**，不是我这一单的那个目录（上一轮我就提过，还是没改）。
  2. **表里列出了第 1 版、第 2 版，可我点不开其中任何一版。**
     我要去文件夹里自己认文件名（`PI20261021001_v1.pdf`），认错了发错版给客户，
     **信用证/大客户那里就是单证不符点。**
  3. 表里**也不显示文件名**，我连"这版叫什么"都看不到。
- **想要什么**：**每一行直接给一个「打开」/「重新打印」按钮**，点开就是那一版的文件。
  最好再给一个「复制这版的 PDF 到微信/邮件目录」。
- **重要性**：**有点烦**。

### N35. **订单列表搜不到款号**（有点烦）

- **场景**：老板问"TS-001 这个月出了多少件"。或者客户问"上次那个 POLO 的价格是多少"（报价单能搜款号了，订单不行）。
- **我现在的做法**：订单列表搜索框占位符写的是「搜索订单号 / PI号 / 客户 / PO号」。
  我输 `TS-001` → **0 条**（我查了后台的 SQL，搜的就是订单号/PI号/客户PO/客户名四个字段，**没有款号**）。
  我只能导出「款号明细台账.csv」，用 Excel 打开再筛。
- **痛在哪**：
  1. **报价单能按款号搜，订单不能** —— 同一个系统两套标准，很别扭。
  2. 一年 200 单，退税核款号、老板问某款出货量，都得走"导出 → Excel → 筛选"这一套。
  3. 顺带：**订单列表也没有"待收"列**（跟 N29 是一条），筛不出"哪几单尾款没到"。
- **想要什么**：**订单列表的搜索框也认款号**（顺带认颜色、尺码更好）。再加一个「待收」列。
- **重要性**：**有点烦**。
