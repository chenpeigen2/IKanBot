## 二、B2 参数路由收口——**成立，且没有过度放行**

1. **共享匹配器行为**（已实跑）：`matchRoute('/api/files/images/:name',
   '/api/files/images/probe.png')` → `true`；
   `matchRoute('/api/files/images/:name', '/api/files/images/probe.png/extra')` → `false`；
   空参数 `…/images/` → `false`；精确路由优先于参数路由；对象路由表返回原对象。
2. **B2 接线**（已实跑）：`audit-ipc-wiring.cjs` 的 `missingServerRoute` 已改用
   `findServerRoute(r.path, serverRoutes)`，不再用 `serverRoutes.includes()`。
3. **红验证 1**（已复现）：临时把 `customers:list` 路径改成
   `/api/files/images/probe.png`，`npm run audit:ipc` **exit 0**——参数路由被正确接受。
4. **红验证 2**（已复现）：改成 `/api/files/images/probe.png/extra`，`npm run audit:ipc`
   **exit 1**，输出 `customers:list → /api/files/images/probe.png/extra`——多一段仍报红。
5. 篡改后的 `electron/remote/client.ts` 已还原，`git diff` 实核为零。
