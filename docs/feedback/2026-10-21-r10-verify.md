## 二、三个不变量（各拿一个数，三处对）

**① 待收三处一个数 —— 过**
- 订单 SO20261021001：订单详情卡「待收 USD 4,805.00」= 工作台待办「已收 3000.00 / 待收 4805.00」= 客户页订单行「待收 USD 4,805.00」，三处一个数（r10-order118 / r10-dashboard / r10-customer-detail）。
- 公司级：工作台 63,956.75 = 手算一致；客户页 57,879.25 = 手算一致；打样单列表单行 1,215.50 与工作台口径一致。
- 转单抵扣后：工作台 62,955.75 = 62,741.25（订单）+ 214.50（新打样单），该扣的扣了、没汇率的没混进来（r10-dashboard3.png）。

**② 毛利三处一致（或三处都诚实）—— 过**
- 订单 118 详情「毛利 USD 3,150.00 / 成本 4,425.00」（这单成本录全了，敢给数）。
- 工作台「本月毛利 —」+「本月有单成本没录全，毛利不可信（宁可给你「—」）」；报表「累计毛利 —」+黄条点名「2026-10（1 单）…补录入口：订单 → 商品明细 → 成本」。查库：订单 121（TS-900）unit_cost = NULL，就一单 → **三处都没给漂亮数字，口径同一个**。
- 客户页 Acme「累计毛利 32,818.50」= (3150+1440)×7.15，Acme 两单成本都录全，敢给数，自洽。

**③ PI / CI / 报价单 / PL 四张纸合计 —— 过（附一条口径备注）**
- PI 预览纸面 `TOTAL / 合计 = 7805.00`；CI 预览 `TOTAL / 合计 7805.00 | Total Payable: USD 7,805.00` —— 两张一模一样（r10-docs-total2.png 探针）。
- 报价单预览 `合计（含费用）… 5540.00` = 报价列表上印的 `USD 5,540.00`（r10-quo-probe2.png）。它是没转单的独立草稿，本来就不该等于订单的 7805，不构成矛盾。
- **PL 纸上不印钱**：它的 TOTAL 行是「4 箱 / 4 cartons、900 件、毛 128.70、净 117.00、0.480 CBM」——900 = 订单总件数、毛 = 净 × 1.1（库里 grossWeightFactor），箱数口径自洽。装箱单不印金额是行业惯例，我不挑；但按我「纸面要写清口径」的老规矩记一笔：**这轮 PI=CI，PL 无金额行，报价单自成一套，四张纸没有互相打架的数**。
- 存档表两版金额都是 7805.00 = 纸面 TOTAL，存档口径也对上了。

## 三、本轮新发现

**N-1【很重要】报价单的中文拦截，界面上一个字都看不见**
- 场景：客户把报价转成订单后，我在报价列表想把这张报价作废/清掉，点「删除」→ 弹「确认删除报价单 Q20261021001？」→ 我点确定。
- 现在的做法：后台确实拦住了（报价还在，没丢凭据），**但屏幕上什么提示都没有**——没 toast、没红字、列表也不刷新。
- 痛在哪：我会以为按钮坏了，反复点；更糟的是我可能认为"已经删掉了"，回头跟客户对账时才发现两张单据的关系早没了着落。你们自己说的"客户赖账得有凭据"，拦截做了看不见 = 白做一半。
- 想要什么：点删除，要么弹出那句中文（「已经转成订单 SO…，要作废请改状态」），要么至少红条告诉我为什么没删掉。跟客户页 `Customers.tsx` 那个 catch 一样就行。
- 重要性：**很重要**（同一份代码里一处接了 catch、一处没接，又是"修一处漏一处"）。

**N-2【有点烦】打样单转订单，直接落成「草稿」，也不问 PI 发不发**
- 场景：客户邮件回"样品 OK，按这个下大货"，我点转单，以为这单就算进来了。
- 现在的做法：转完跳到 SO20261021005，收款状态是**草稿**，顶部黄条提醒我改；而草稿单不进销售额、不进待收、工作台不提醒。报价单转单那条路会问一句「PI 发不发」，打样转单不问。
- 痛在哪：忘了改状态，这单在报表和待收里就是不存在的，月底对账少一笔，我得自己想起来。
- 想要什么：转单时也问一句（跟报价转单一样二选一），或者至少转完别落在"系统当它不存在"的状态。
- 重要性：**有点烦**，但踩上了就是对账事故。

**N-3【有点烦】打样单号不查重，列表里出现两张一模一样的号**
- 场景：我这轮为了造测试数据手工插了一张 SMP20261021002，系统按计数器生成的下一张也叫 SMP20261021002，列表里两张同号并排，谁是谁分不清。
- 现在的做法：照常存进去，不报错。
- 痛在哪：单号是我的凭据，撞号＝客户问"你那张 SMP…002 寄了吗"我答不上来是哪张。正常点新建撞不上（计数器在），但恢复备份、手工导库、多台机器都可能撞。
- 想要什么：保存时查一下号，重了就红字拦住，让我换个号。
- 重要性：**有点烦**（这轮是我自己插数据插出来的，正常操作遇不到，但凭据系统值得加一道）。

**测试痕迹说明（不是产品问题）**：本轮我往演示库里动了这些——补了 2 条 doc_versions（指向已存在的 PI PDF，为验 N34）、把报价 Q20261021001 手工标成 converted（为验 N31）、手工插了无汇率旧打样单 SMP20261021002、界面真实新建了一张打样单、真实转出订单 SO20261021005、把 SMP…001 的打样日期改成 9-25（为验超阈值提醒）。`npm run seed` 全清。

**没坏的**：原来好用的——工作台四卡、最近订单金额（USD 7,805.00 = 订单详情含费用合计 = PI 纸面）、报表导出按钮、订单详情五个页签、打样列表横向滚动，本轮都正常，没被这 8 条改出毛刺。
