## 五、请文娟复验的重点

1. **弱提示亲测**（最重要）：开两个窗口（或两台机器连同一个后端），A 开着某张订单的编辑弹窗，
   B 改这张单——A 那边 30 秒内（或点一下别的程序再切回来）应出现黄条「刚被别人改过…」，
   不弹窗不拦操作；点「重新载入」（详情页）或关掉重开（弹窗）后黄条消失。
2. **409 老规矩**：A 开着编辑弹窗不保存，B 改同一单；A 再点「保存修改」——应被人话拦下
   （「这条记录刚被别人改过，请刷新后再试」），刷新后能正常保存。
3. **收款幂等不回归**：双击「登记收款」还是只落一笔。
4. **报价单/打样单同测一遍 409**：这两张单本轮才真正接上锁（以前界面没传凭据）。
5. 数字对表：e2e 2470 / 双模式 140 / 数据层 76 / HTTP 211；sweep 九路由与记账里的新基线一致。
6. 截图矩阵：docs/ui/r63/ 七张，逐张能对上你亲手点出来的状态。
