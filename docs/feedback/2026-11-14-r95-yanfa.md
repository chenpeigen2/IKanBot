1. **远端 catch toast 态实拍**（已做并验过，docs/ui/r95/）：R84 以来「toast 态无本机配方」

   等 8 秒后 fresh 引用点击 → error toast（5200ms 寿命）落入截图。toast 全文含 R84 修的
   尾巴「——请先不要录单，立即联系技术支持」（R95 首版误写 R92——复验 git 考古定案该尾巴由 R84 eb98869 引入，R92 的正身是锚点竞态修复；已改回）。
   实验教训两条记进 r95 README：fetch 轮询测死亡会被 800ms 超时误判（click 落在死前拍成
   绿框）——换确定性时序；error toast 寿命 5200ms（ui.tsx:510），capture 要落在点后 3 秒内。
2. **r94 README 三处小账清扫**（已做并验过，R94 复验挑的）：备份包名笔误改准
