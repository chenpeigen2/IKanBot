## 二、本轮新发现的问题

### N20. 成本没录全之后，整个系统里**没有任何地方能补成本** —— 死胡同

- **场景**：客户临时加一个款号，这个款号还没进商品库。我在报价单里「+ 手工加一行」，
  填了款号、单价、数量，转成订单。这一行成本是空的。
- **我现在的做法**：订单详情明明白白告诉我「**有 1 行成本未录入，毛利不算**」，
  报表黄条也告诉我「**先到订单里补了成本再跟老板对数**」。
  **然后我去找了一圈，没找到地方补。**
  - 订单「商品明细」表里，**成本那一栏是灰字死文本**（`it.unitCost == null ? '—' : …`），不是输入框；
    数量、单价、颜色、尺码都能改，**就成本不能**。
  - 「编辑」弹窗里没有成本栏。
  - 商品库补了成本价，**也不会回填到已有的订单行**（库里没有任何回填逻辑）。
- **痛在哪**：
  1. **系统把我推进了一个死胡同。** 上一轮你们把"假毛利"堵住了，这很好；
     但堵住之后**没给我留出口**。报表那句提示是**指错地方**的。
  2. **补不了 = 永久失效。** 这一单的毛利永远是「—」，这个客户的「累计毛利」永远是「—」，
     这个月的月报那一行永远是「—」。**我月底拿着一个横杠去跟老板对数，对不出来。**
  3. 唯一的绕法是：先去商品库把这个款号建出来（带成本价）→ 回订单把那一行**删掉** →
     再点「+ 添加商品」从商品库选回来 → **数量、单价、颜色、尺码全要重敲一遍**。
     **为了一个成本数字，代价是一整行数据重录。**（我试过这条路能走通，但没人会天天这么干。）
- **想要什么**：
  1. **订单明细表里，成本那一栏变成能填的输入框**（跟数量、单价一样，填完失焦就存）。
     空的时候别只给一个「—」，给一句「**未录，点这里补**」。
  2. 或者：商品库改了成本价以后，**把同款号、成本还空着的订单行自动补上**（并记一条操作历史）。
  3. 至少，报表那句黄条**别把我往订单里指** —— 指一个真能补的地方。
- **重要性**：**很重要**。（不是算错钱，是"让我自己给自己下套"：先给我一个诚实的「—」，再不给路走。）

### N21. 工作台首页的「本月毛利」**还是那个假的数字**，跟报表页自相矛盾

- **场景**：月底老板问"这个月赚了多少"。我打开工作台。
- **我现在的做法**：
  - 工作台：「本月销售额 CNY 110,431.75 / **毛利 CNY 49,621.00**」← 截图 `r4-dashboard-final.png`
  - 报表页：「累计毛利 **—**」+ 黄条「有成本没录全的单：2026-10（1 单）。
    **这些单的毛利是按 0 成本算出来的，偏大**，先到订单里补了成本再跟老板对数。」
  - **两个页面两个说法。**
- **痛在哪**：
  1. 我查了库，工作台那个 49,621.00 = 销售额 110,431.75 − 成本 60,810.75，
     而 **60,810.75 里那单没录成本的订单是按 0 成本算的**，
     所以毛利里**至少虚增了 850 USD ≈ CNY 6,077.50**。
  2. **老板第一眼看的恰恰是工作台**（打开就是首页），而且工作台是最容易被截图发微信的页面。
     他记住的是工作台那个数；我拿着报表说"这个数不能信"，**他只会觉得软件坏了**。
  3. 上一轮把"假毛利"在**报表页、客户页、订单详情页**都堵了，**唯独漏了工作台**。
     改动只做了 3/4，**结果是最常看的那一页在骗人**。
- **想要什么**：**工作台的本月毛利跟报表一个口径** —— 有成本没录全的单，
  这个月的毛利也给「—」（或者至少在数字旁边标一句"含 1 单成本未录，偏大"）。
  **宁可工作台也显示「—」，也不要一个我自己知道是假的数字。**
- **重要性**：**很重要**。

### N22. "我一共还欠客户多少钱" —— **三个地方三个数**

- **场景**：老板问"外面还有多少钱没收回来？"
- **我现在的做法**：我去三个地方抄，结果抄出三个数：

  | 地方 | 显示 | 它的口径 |
  |---|---|---|
  | 订单详情（SO20261021001） | 待收 **USD 4,855.00** | 货值 + 运费保险 − 已收 ✅ |
  | **工作台「待收款金额」** | **CNY 82,546.75** | 未结清订单的**全部货值**；**不减已收款**，**不含运费保险** ❌ |
  | 客户页「未收金额」 | Acme 55,019.25 + Nordic 6,077.50 = **CNY 61,096.75** | 货值 − 已收；**不含运费保险** ❌ |

- **痛在哪**：
  1. **正确的数是 CNY 62,741.25**（= 4,805 + 3,120 + 850 = 8,775 USD × 7.15，我用 SQL 算过）。
     **工作台比实际多报 19,805.50 元，虚高 31.6%**；客户页比实际**少报** 1,644.50 元（运费保险没进去）。
  2. 这不是显示问题，是**口径问题**：工作台那张卡的 SQL 就是
     `SUM(quantity * unit_price * exchange_rate)` over 未结清订单，**压根没减 `payments` 表**。
     我把 `pending_amount` 单独跑了一遍：**82,546.75 = (7,575 + 3,120 + 850) × 7.15**，
     也就是**未结清订单的货值原封不动**，已收的 3,000 美元在里面**一分没扣**。
  3. 上一轮你们把收款状态流转、催尾款提醒都改成按含费用算了，
     **唯独工作台这张卡的 SQL 没动**。
  4. **老板问一句我得先自己拿计算器算一遍再回答** —— 这比没有数字还麻烦。
- **想要什么**：**一个口径，一个数。** 工作台「待收款金额」改成
  `Σ(含费用合计 − 已收)`，跟订单详情、客户页对上。**别让老板从三个地方听到三个答案。**
- **重要性**：**很重要**。

### N23. 打样单里**公司垫的钱，系统里根本没有这一笔应收** —— 收不回来了

- **场景**：客户要打样，我寄 DHL，**快递费 180 USD、样品费 50 USD，都是公司先垫的钱**。
  客户签收以后一句"样品费下次下单抵扣"，或者干脆不提。
- **我现在的做法**：打样单上记着「样品费 50.00 / 快递费 180.00 / 合计 230.00」。
  但我打开工作台 —— **待收款金额还是 CNY 82,546.75，一个数都没多**；
  催款提醒里没有；客户页「未收金额」里也没有。
- **痛在哪**：
  1. **这 230 USD 是公司真金白银垫出去的，系统里没有第二份记录，年底对账我根本想不起来跟谁要过。**
     一年下来几十张打样单，几千美金就这么飘着。
  2. 我做外贸十一年，**样品费和快递费是要跟客户算的**（要么另收，要么大单里抵扣）。
     系统现在只帮我"记了一笔成本"，**没帮我"记一笔应收"**。

### N24. 打样单是个孤岛 —— 客户确认样品后，我要从头再敲一遍

- **场景**：客户收到样品说"OK，就这个颜色这个码，下 5000 件"。这是打样→下单最常见的路径。
- **我现在的做法**：打开打样单，抄下款号 PL-002、颜色 Navy、尺码 L、样品单价 25 →
  新建订单 → 选客户 → 从商品库选款 PL-002 → 重新选 Navy/L → 填 5000 件 → 填单价。
  **打样单上的信息一个都带不过去。**
- **痛在哪**：
  1. 打样单成了**一本"只进不出"的账**：打完样就断了，客户确认了还得重敲一遍。
  2. 客户打样时说的"要 5000 件"、改过的颜色、特殊要求，全写在打样单备注里，**转订单时带不走**。
- **想要什么**：**打样单上点一下「转成订单」** —— 客户、款号、颜色、尺码、单价自动带过去，

- **重要性**：**有点烦**。（不致命，但我一天能碰到两三次。）

### N25. 打样单没有「寄出日期」「签收日期」

- **想要什么**：寄出日期、签收日期两个字段。
- **重要性**：**有点烦**。
